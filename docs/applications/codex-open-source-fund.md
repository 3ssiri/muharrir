## Project

## Brief Description

> Muharrir is an MIT-licensed, local-first Arabic/English prompt-engineering workspace that turns rough ideas, documents, and requirements into structured, reusable AI prompts. It combines real RTL support, guided refinement, browser-side document parsing, provider choice, and web/desktop builds without operating a central user-data backend.

> We would use API credits to build and run open-source Arabic/English evaluation fixtures, test OpenAI-compatible tool calling and streaming, reproduce provider regressions, generate synthetic edge cases, review pull requests, and validate releases.
