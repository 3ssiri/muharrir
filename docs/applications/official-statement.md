# Official Statement

## Primary One-Liner

Muharrir is a local-first Arabic/English prompt engineering workspace that turns rough ideas, documents, and requirements into structured, reusable AI prompts through guided refinement.

## Arabic One-Liner

محرر مساحة عمل محلية أولا بالعربية والإنجليزية لتحويل الأفكار والمستندات والمتطلبات الخام إلى موجهات ذكاء اصطناعي منظمة وقابلة لإعادة الاستخدام عبر تحسين تفاعلي موجّه.

## Short Positioning

Muharrir is not a generic chat app. It is a workflow layer for prompt engineering: it helps users clarify intent, choose improvement directions, generate structured prompt proposals, and keep control of their data through local-first storage and provider choice.

## Provider-Specific Lines

### OpenAI

Muharrir uses OpenAI-compatible chat and tool-calling flows to help users transform vague ideas and local document context into structured prompts for downstream AI work.

### Anthropic

Muharrir is prepared as a local-first prompt engineering workspace, with native Claude API support planned as the next integration milestone for running guided prompt refinement directly on Claude.
