# دليل النشر

يشرح هذا المستند بالتفصيل كيفية نشر المشروع على GitHub و Vercel.

## التحضير

### 1. التأكد من أن المشروع يعمل بشكل صحيح

قبل النشر، يُرجى الاختبار محليًا أولًا:

```bash
npm install
npm run build
npm run start
```

افتح http://localhost:3000 للتأكد من أن التطبيق يعمل بشكل طبيعي.

### 2. تنظيف الملفات غير الضرورية

تم تهيئة المشروع باستخدام `.gitignore`، ولن يتم رفع الملفات التالية:
- `node_modules/`
- `.next/`
- ملفات الاختبار (`test-*.js`)
- ملفات لقطات الشاشة (`screenshots/`)
- مجلدات أدوات الذكاء الاصطناعي (`.ace-tool/`, `.ai_memory/` وما إلى ذلك)


## النشر على GitHub

### الخطوة 1: تهيئة مستودع Git

إذا لم تتم تهيئة Git بعد، نفّذ:

```bash
git init
git add .
git commit -m "Initial commit: Interactive Prompt Iterator"
```

### الخطوة 2: إنشاء مستودع GitHub

1. افتح [GitHub](https://github.com)
2. انقر على "+" في أعلى اليمين ← "New repository"
3. املأ معلومات المستودع:
   - **Repository name**: مثلًا `prompt-iterator`
   - **Description**: مُكرِّر المطالبات التفاعلي
   - **Public/Private**: اختر حسب الحاجة
   - **لا** تُحدِّد "Initialize with README" (لدينا README بالفعل)

4. انقر على "Create repository"


### الخطوة 3: دفع الكود إلى GitHub

انسخ الأوامر التي يوفرها GitHub، أو نفّذ:

```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

> استبدل `YOUR_USERNAME` و `YOUR_REPO_NAME` بمعلوماتك الفعلية

### الخطوة 4: التحقق

افتح صفحة مستودع GitHub الخاص بك، وتأكد من رفع الكود بنجاح.


## النشر على Vercel

### الطريقة الأولى: عبر لوحة تحكم Vercel (موصى بها)

#### الخطوة 1: ربط GitHub

1. افتح [لوحة تحكم Vercel](https://vercel.com/dashboard)
2. إذا لم يكن لديك حساب، سجّل/سجّل الدخول باستخدام حساب GitHub
3. انقر على "Add New..." ← "Project"


#### الخطوة 2: استيراد المستودع

1. في صفحة "Import Git Repository"، ابحث عن مستودعك
2. انقر على "Import"

#### الخطوة 3: تهيئة المشروع

سيكتشف Vercel تلقائيًا أن هذا مشروع Next.js، ويهيّئ:
- **Framework Preset**: Next.js
- **Build Command**: `npm run build`
- **Output Directory**: `.next`
- **Install Command**: `npm install`

عادةً لا حاجة لتعديل هذه الإعدادات.


#### الخطوة 4: متغيرات البيئة (اختياري)

إذا احتجت إلى تعيين إعدادات API افتراضية، انقر على "Environment Variables":

- `NEXT_PUBLIC_DEFAULT_API_KEY`: مفتاح API الافتراضي (غير موصى به)
- `NEXT_PUBLIC_DEFAULT_BASE_URL`: نقطة نهاية API الافتراضية
- `NEXT_PUBLIC_DEFAULT_MODEL`: النموذج الافتراضي

> ⚠️ ملاحظة: نظرًا لأن هذا تطبيق واجهة أمامية بحتة، فإن متغيرات البيئة ستُكشف للعميل، ولا يُنصح بتعيين مفتاح API حقيقي هنا


#### الخطوة 5: النشر

1. انقر على زر "Deploy"
2. انتظر اكتمال البناء (يستغرق عادةً من 1 إلى 3 دقائق)
3. بعد نجاح البناء، سيوفر Vercel عنوان URL، مثل:
   - `https://your-project.vercel.app`

#### الخطوة 6: فتح التطبيق

انقر على عنوان URL المُقدَّم لفتح تطبيقك. عند الاستخدام لأول مرة، يجب تهيئة مفتاح API في الإعدادات.


### الطريقة الثانية: عبر Vercel CLI

#### تثبيت Vercel CLI

```bash
npm install -g vercel
```

#### تسجيل الدخول

```bash
vercel login
```

#### النشر

نفّذ في المجلد الجذر للمشروع:

```bash
vercel
```

اتبع التعليمات لإكمال التهيئة. عند النشر لأول مرة، سيُسأل عن:
- اسم المشروع
- هل تريد الربط بمشروع موجود
- إعدادات المشروع

#### النشر للإنتاج

```bash
vercel --prod
```


## النشر التلقائي

### تكامل GitHub

سيراقب Vercel تلقائيًا التغييرات في مستودع GitHub:

- **Push to main**: يُشغِّل نشر الإنتاج تلقائيًا
- **Pull Request**: يُنشئ نشر معاينة تلقائيًا
- **كل التزام (commit)**: يُولِّد عنوان URL معاينة فريد

### عرض حالة النشر

1. افتح لوحة تحكم Vercel
2. اختر مشروعك
3. اعرض علامة التبويب "Deployments"


## النطاق المخصص (اختياري)

### إضافة نطاق مخصص

1. اختر المشروع في لوحة تحكم Vercel
2. ادخل إلى "Settings" ← "Domains"
3. أدخل نطاقك، ثم انقر على "Add"
4. اتبع التعليمات لتهيئة سجلات DNS

### تهيئة DNS

يدعم Vercel طريقتين:
- **A Record**: يشير إلى عنوان IP الخاص بـ Vercel
- **CNAME**: يشير إلى `cname.vercel-dns.com`


## الأسئلة الشائعة

### فشل البناء

**المشكلة**: ظهور خطأ في الاعتماديات أثناء البناء

**الحل**:
```bash
# تنظيف الاعتماديات
rm -rf node_modules package-lock.json
npm install
npm run build
```


### متغيرات البيئة لا تعمل

**المشكلة**: متغيرات البيئة المُعيَّنة لا يمكن الوصول إليها في التطبيق

**الحل**:
- تأكد من أن متغيرات البيئة تبدأ بـ `NEXT_PUBLIC_`
- يجب إعادة النشر بعد تعديل متغيرات البيئة
- تحقق في لوحة تحكم Vercel من أن متغيرات البيئة مُعيَّنة بشكل صحيح


### تعذُّر الوصول بعد النشر

**المشكلة**: نجح النشر لكن فتح عنوان URL يُظهر خطأ

**الحل**:
1. تحقق من سجلات نشر Vercel بحثًا عن أخطاء
2. تأكد من صحة تهيئة scripts في `package.json`
3. تحقق من توافق إصدار Next.js

### فشل طلبات API

**المشكلة**: فشل طلبات API بعد النشر

**الحل**:
- تحقق من تهيئة CORS
- تأكد من تهيئة مفتاح API في إعدادات الواجهة الأمامية
- تحقق من صحة Base URL


## اقتراحات لتحسين الأداء

### 1. تفعيل Vercel Analytics

فعّل Analytics في لوحة تحكم Vercel لمراقبة الأداء.

### 2. تهيئة التخزين المؤقت (الكاش)

سيُهيِّئ Vercel التخزين المؤقت للموارد الثابتة تلقائيًا، دون الحاجة إلى تهيئة إضافية.

### 3. تحسين الصور

استخدم مكوّن Next.js Image لتحسين الصور تلقائيًا.


## اقتراحات الأمان

### 1. لا تُضمِّن مفتاح API بشكل ثابت في الكود

يجب أن يُهيِّئ المستخدم جميع المعلومات الحساسة في إعدادات الواجهة الأمامية.

### 2. استخدم متغيرات البيئة

إذا احتجت إلى تعيين قيم افتراضية، استخدم متغيرات البيئة بدلًا من التضمين الثابت.

### 3. حدِّث الاعتماديات بانتظام

```bash
npm audit
npm update
```

## المراقبة والصيانة

إذا واجه الإصدار الجديد مشكلة، يمكنك التراجع إلى الإصدار السابق بنقرة واحدة في لوحة تحكم Vercel.
