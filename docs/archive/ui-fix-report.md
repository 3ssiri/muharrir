## محتوى الإصلاح

### 1. ✅ إزالة مُحدِّد النموذج المكرر
**المشكلة**: يوجد مُحدِّد نموذج وزر إعدادات في كل من Header أعلى الصفحة ومنطقة علامات التبويب (الإطار الأحمر في الصورة 1)
**الإصلاح**:
- إزالة مجموعة الأزرار اليمنى في منطقة علامات التبويب
- الإبقاء فقط على مُحدِّد النموذج وزر الإعدادات في Header
**الملف**: `src/app/page.tsx` (الأسطر 676-704)

### 2. ✅ توسيع حدود مربع الحوار في وضع ملء الشاشة
**المشكلة**: يحتاج مربع الحوار في وضع ملء الشاشة إلى حدود أكثر وضوحًا (الصورة 2)
**الإصلاح**:
- إضافة الفئة `border-4` إلى DialogContent
- أصبحت الحدود أكثر وضوحًا، وتحسّن المظهر البصري
**الملف**: `src/components/auto-resize-textarea.tsx` (السطر 122)

### 3. ✅ عرض معاينة الملف عند التمرير (hover)
**المشكلة**: محتوى الملف يُعرض مباشرةً في الرسالة، مما يشغل مساحة (الصورة 3)
**الإصلاح**:
- تعديل منطق عرض الرسالة لإظهار النص الذي أدخله المستخدم فقط
- عرض محتوى الملف عبر Tooltip عند التمرير على أيقونة الملف
- تحديث مكوّن FileAttachmentIcon لدعم المعامل fileContent
- يعرض Tooltip معاينة لأول 2000 حرف من محتوى الملف
**الملفات**:
  - `src/components/file-attachment-icon.tsx` (إضافة Tooltip)
  - `src/app/page.tsx` (الأسطر 791-849)

### 4. ✅ ربط اختصار لوحة المفاتيح للبحث
**المشكلة**: مربع البحث لا يحتوي على اختصار لوحة مفاتيح
**الإصلاح**:
- إضافة اختصار Ctrl+K (Windows/Linux) أو Cmd+K (Mac)
- الضغط على الاختصار يُركّز مربع البحث تلقائيًا
- إذا كان الشريط الجانبي مطويًا، يُفتح تلقائيًا
- يعرض placeholder مربع البحث تلميح الاختصار
**الملف**: `src/components/chat-sidebar.tsx` (الأسطر 93-110، 217-223)

### 5. ✅ دعم ref في مكوّن Input
**المشكلة**: مكوّن Input لا يدعم ref، مما يؤدي إلى عدم قدرة الاختصار على التركيز
**الإصلاح**:
- تغيير مكوّن Input لاستخدام React.forwardRef
- إضافة displayName
**الملف**: `src/components/ui/input.tsx`
