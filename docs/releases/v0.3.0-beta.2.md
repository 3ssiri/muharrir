# Muharrir v0.3.0-beta.2 Release Notes

Date: 2026-08-02

Status: public source/demo prerelease. **Not** a signed multi-platform desktop
updater release — see [RELEASING.md](../RELEASING.md).

## Highlights

- Native Anthropic Claude Messages API (tool-use + streaming) for the built-in
  Anthropic provider.
- Arabic-first prompt proposal structure in the default system prompt.
- Localized demo mode (full Arabic sample when UI locale is `ar`).
- Persona prompt packs: developers, educators, researchers, creators.
- Shared provider `/models` parser with fixtures and clearer browser CORS docs.
- React Compiler ESLint rules adopted and violations fixed.
- Expanded keyboard / screen-reader accessibility + Playwright a11y spec.
- Desktop release runbook and signing-secret preflight (fail-fast before the
  build matrix).

## Product Changes

### Providers

- Claude native adapter: request shape, tool schema mapping, stream event
  conversion into Muharrir’s internal UI protocol.
- Unit coverage for Anthropic headers/body and streamed tool-use parsing.
- `parseModelsResponse` shared helper; OpenAI / Anthropic / Ollama / malformed
  fixtures; settings connection check and Ollama detection use it.

### Arabic & presets

- Fixed Arabic section headers and phrasing rules for `propose_prompt`.
- Demo content moved into the `demo` i18n namespace (locale-aware).
- Four persona packs in the preset gallery with ar/en locale parity tests.

### Accessibility

- Localized `aria-label`s on icon-only controls (theme, settings, sidebar,
  favorites, file upload, prompt card, header actions).
- Sidebar sessions keyboard-operable (`role="button"`, Enter/Space, focus ring).
- New `tests/accessibility.spec.js` (lang/dir, accessible names, focus order,
  settings dialog trap, keyboard session activation).

### Quality & desktop release tooling

- Four `eslint-config-next` 16 React Compiler rules enabled; hydration-safe
  `useSyncExternalStore` mount flags; render-derived filters; adjust-state-
  during-render resets; no components created during render.
- `docs/RELEASING.md` runbook for signed Tauri releases.
- `scripts/tests/validate-signing-secret.js` wired into `build-desktop.yml`
  (with `npm ci`) ahead of the matrix.
- Desktop workflow still skips prerelease tags containing `-` for signed
  updater artifacts (by design).

## Verification

Run on the release commit before tagging:

```bash
npm run lint
npm run typecheck
npm run test:unit
npm run build
# optional: npm test  # Playwright (starts its own dev server)
```

## Not in this prerelease

- Signed Windows / macOS / Linux installers with updater `.sig` + `latest.json`
  (blocked until valid `TAURI_SIGNING_*` GitHub secrets — see RELEASING.md).
- Real-key smoke of Claude / OpenAI-compatible providers (manual maintainer gate).
- Codex / OpenAI grant form submission (applicant-only).
