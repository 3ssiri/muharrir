# Muharrir v0.3.0-beta.1 Release Notes

Date: 2026-07-08

Status: planned public beta notes. Use these notes for the first public release or adapt them if the final tag changes.

## Highlights

- Local-first Arabic/English prompt engineering workspace.
- Demo mode for first-time users with no external AI provider call.
- One-click local Ollama setup when Ollama is detected.
- OpenAI-compatible provider settings with clearer no-key handling for local providers.
- Static-export web app plus Tauri desktop architecture.
- Browser-side PDF/DOCX parsing.
- Local IndexedDB conversation history and favorites.
- Desktop API key storage through OS Keychain when available.
- OSS-ready documentation, governance files, privacy notes, security policy, and contribution guide.
- Anthropic/OpenAI application package for startup, builder, and grant submissions.

## Product Changes

- Added a clear first-run path for trying Muharrir without an API key.
- Added local Ollama detection through `/v1/models`.
- Added "Use local Ollama" onboarding action.
- Added a provider status badge in the main header.
- Improved local model selection so chat-capable models are preferred over embedding/OCR/vision models.
- Added fallback text when a local model replies with plain text instead of calling Muharrir tools.
- Improved provider and CORS documentation.

## Open Source Readiness

- Updated package identity and metadata.
- Added MIT license alignment.
- Added `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, and `CHANGELOG.md`.
- Added GitHub issue templates, PR template, and labels file.
- Added roadmap, privacy documentation, provider guide, and grant/application materials.

## Known Limits

- Native Claude API support is planned but not yet implemented.
- Some providers may fail from a regular browser because of CORS; desktop mode can be a better fit.
- Desktop updater signing requires Tauri signing secrets in CI.
- The repository should only be made public after the owner confirms the release gate.
