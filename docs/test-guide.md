# دليل الاختبار

## خطوات الاختبار السريع

### 1. تشغيل التطبيق
```bash
npm run dev
```

### 2. اختبار وظيفة المحادثة الجديدة
- أرسل رسالة لإنشاء محادثة
- انقر على زر "محادثة جديدة"
- ✅ تحقق: يجب أن يبقى سجل الشريط الجانبي محفوظاً

### 3. اختبار المحادثة الجديدة في صفحة المفضلة
- انتقل إلى تبويب "المفضلة"
- انقر على زر "محادثة جديدة"
- ✅ تحقق: يجب أن ينتقل تلقائياً إلى تبويب "المحادثة"

### 4. اختبار تخطيط رفع الملفات
- ارفع 2-3 ملفات
- ✅ تحقق: تظهر بطاقات الملفات أعلى حقل الإدخال
- ✅ تحقق: لا يوجد داخل حقل الإدخال سوى زر الرفع، دون أن يُزاحَم

### 5. اختبار موضع زر المفضلة
- ولّد مطالبة
- ✅ تحقق: زر المفضلة على يمين عنوان البطاقة
- بدّل بين "عرض المعاينة" و"تفاصيل البنية"
- ✅ تحقق: يبقى موضع زر المفضلة ثابتاً

### 6. اختبار معاينة ملء الشاشة
- انقر على زر التكبير
- ✅ تحقق: تشغل نافذة المعاينة 90% من عرض الشاشة

### 7. اختبار عرض النموذج
- اعرض نموذج اقتراحات اتجاه التحسين
- ✅ تحقق: عرض النموذج ثابت، ولا يكون ضيقاً جداً

node scripts/tests/test-7-fixes.js
