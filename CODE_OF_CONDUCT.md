# Code of Conduct

Muharrir aims to be a practical, welcoming open-source project for Arabic and English AI tooling.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially across languages and cultures.
- Keep feedback specific and actionable.
- Prefer clear technical discussion over personal criticism.
- Help newcomers understand project constraints such as local-first storage, RTL support, and static export.

## Unacceptable Behavior

- Harassment, insults, discrimination, or intimidation.
- Publishing private information, API keys, prompts, documents, or personal data.
- Repeatedly derailing technical discussions.
- Abusive language or hostile review behavior.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code of conduct. Repeated or severe violations may result in being blocked from project spaces.

Report concerns privately to the maintainer through GitHub: https://github.com/3ssiri
