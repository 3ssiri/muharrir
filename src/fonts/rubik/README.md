# Rubik

Local copies of [Rubik](https://github.com/googlefonts/rubik) for `next/font/local`.

- Source: [google/fonts ofl/rubik](https://github.com/google/fonts/tree/main/ofl/rubik) variable font `Rubik[wght].ttf`
- Weights: 300, 400, 500, 600, 700, 800 (instanced from the variable font)
- Subsets: Latin + Arabic (same as the previous `next/font/google` config)
- License: SIL Open Font License 1.1 — see `OFL.txt`

These files are committed so production builds never fetch Google Fonts.
